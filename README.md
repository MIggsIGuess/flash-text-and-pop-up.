# Text Flash Animator - Complete Web Application

## Overview
Text Flash Animator is a modern, single-page web application that allows users to create stunning text animations and customizable popup messages entirely through an easy-to-use interface. No backend required - everything runs in the browser!

## Project Location
📁 `C:\Users\name\TextFlashAnimator\`

Files:
- `index.html` - Main HTML structure
- `styles.css` - Complete styling with dark theme
- `script.js` - Full JavaScript functionality

## How to Use

### Opening the Application
Simply open the `index.html` file in any modern web browser:
```
file:///C:/Users/name/TextFlashAnimator/index.html
```

## Core Features Implemented

### 1. ✨ Text Animation Mode
- **Animation Types**: 9 different animation styles
  - Left to Right
  - Right to Left
  - Top to Bottom
  - Bottom to Top
  - Diagonal
  - Flash (Static)
  - Bounce
  - Rotating
  - ZigZag

- **Animation Controls**:
  - Text input for custom content
  - Speed slider (0.5x - 5x)
  - Size slider (20px - 200px)
  - Rotation slider (0° - 360°)
  - Continuous loop toggle
  - Random pattern toggle

### 2. 🎨 Text Styling Controls
- **Colors**:
  - Text color picker with live preview
  - Background color picker
  - Gradient background support
  - Gradient end color selector

- **Typography**:
  - 7 font family options
  - Bold, Italic, Underline toggles
  - Text shadow controls (X, Y offset, blur, color)
  - Glow effect controls (intensity, color)
  - Outline/Stroke controls (width, color)

### 3. ✨ Visual Effects
- Sparkles effect
- Particles effect
- Fire effect
- Lightning effect
- Confetti effect
- Matrix-style rain
- Floating shapes
- Floating emojis

- **Screen Effects**:
  - Flash intensity slider
  - Motion blur control
  - Screen shake effect

### 4. 💬 Popup Message Mode
Users can create custom popups with:
- Custom title and message
- Adjustable size (width & height)
- Text color customization
- Background color customization
- Border color and width controls
- 4 opening animations (Fade, Scale, Slide, Bounce)

### 5. 🔗 Follow-up Popup System
- Enable/disable follow-up popups
- Configurable delay before showing
- Custom follow-up title and message
- Adjustable follow-up size
- 5 position options (Center, Bottom-Right, Bottom-Left, Top-Right, Top-Left)
- Support for unlimited popup chains

### 6. 📋 Popup Templates
Pre-built templates:
- 👋 Hello World - Welcome message
- ⚠️ Warning - Action confirmation template
- ✅ Success - Success notification
- ❌ Error - Error message
- 🤣 Meme - Humorous template
- ℹ️ Info - Information template

### 7. 💾 Export/Import Features
- **Export Settings**: Download current configuration as JSON
- **Import Settings**: Load previously saved JSON configurations
- **Save Presets**: Save complete configurations locally
- **Load Presets**: Retrieve saved presets anytime
- **Delete Presets**: Remove unwanted preset configurations

### 8. 🎯 User Interface
- **Dark Theme**: Professional neon green (#00ff00) accents on dark background
- **Responsive Layout**: Adapts to different screen sizes
- **Live Preview Area**: Real-time animation preview
- **Side Control Panel**: Organized controls with smooth interactions
- **Tabbed Navigation**: Easy switching between features
- **Real-time Updates**: Changes apply instantly without page refresh
